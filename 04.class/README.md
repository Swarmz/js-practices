## インストール

```bash
npm install
```

## 使い方

### メモの作成

オプションなしで実行すると、メモを作成できます。

```bash
./app.js
```

入力方法は次の2つです。

- 対話入力: メモを入力し、空の行で `Ctrl+D` を押すと保存されます。
- パイプ入力: `echo "メモの内容" | ./app.js` のように実行します。

### メモの一覧表示 (`-l`)

保存されているメモの一覧を表示します。

```bash
./app.js -l
```

### メモの参照 (`-r`)

メモを選択して、内容を表示します。

```bash
./app.js -r
```

### メモの削除 (`-d`)

メモを選択して、削除します。

```bash
./app.js -d
```
